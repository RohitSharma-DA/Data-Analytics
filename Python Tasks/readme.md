# Python for Data Analytics - Practice Tasks Index

This repository contains beginner-level Python practice tasks designed for Data Analytics. Below is an overview of the available practice files and the concepts covered in each.

---

## 📂 Practice Files Overview

| File Name | Topic / Focus | Key Concepts & Operations |
| :--- | :--- | :--- |
| `practiceTask1.py` | Basics, I/O, Operators | Output, user input, variables, multiple assignment, type conversion, arithmetic, comparison, logical, assignment, membership, identity operators, basic calculations |
| `practiceTask2.py` | Control Flow & Conditionals | `if`, `elif`, `else` statements, relational operators, nested conditions, day finders, grading systems, calculators, loan/working age eligibility |
| `practiceTask3.py` | Loops (Basic to Advanced) | `for` loops, `range()`, number series, sum calculation, multiplication tables, string reversal, vowel counting, prime numbers, Fibonacci series, pattern printing |
| `practiceTask4.py` | Data Types, Lists & Dictionaries | `type()`, list creation and modification, dictionary structures, type casting (`int`, `str`, `float`) |
| `practiceTask5.py` | Strings, Lists, & Dictionaries | String manipulation (`.upper()`, `.split()`), list appending and descending sorting (`.reverse=True`), dictionary keys and values iteration |

---

## 🛠️ Detailed File Breakdown

### 1. `practiceTask1.py` - Introduction & Operators
* **Topics:** Basic I/O, variables, data types, type casting, arithmetic, comparison, logical, assignment, membership, and identity operators.
* **Practical Apps:** Simple Interest Calculator, Salary Calculator, Even/Odd checker, Largest of numbers.

### 2. `practiceTask2.py` - Control Flow
* **Topics:** Conditional branching using `if`, `elif`, and `else`.
* **Practical Apps:** Grading systems, leap year checkers, electricity bill calculations, simple calculators, triangle classification, temperature checks.

### 3. `practiceTask3.py` - Loops
* **Topics:** Iterations using `for` loops, step ranges, conditional checks inside loops.
* **Practical Apps:** Prime number verification, Fibonacci series generation, string reversal, vowel counting, pattern printing (stars).

### 4. `practiceTask4.py` - Variables & Data Types
* **Topics:** Checking data types (`type()`), modifying elements in lists, handling dictionary mappings, explicit type conversion.

### 5. `practiceTask5.py` - Strings, Lists, & Dictionaries
* **Topics:** Advanced string methods (`.upper()`, `.split()`), list list operations (`.append()`, `.sort(reverse=True)`), dictionary extraction (`.keys()`, `.values()`).
